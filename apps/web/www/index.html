    Capabilities and honest limits

    • navigator.gpu property: checking… (presence alone is not proof of a usable WebGPU adapter).
    • Informational WebGL2 probe: checking…. Auto/WebGPU routes skip this detached-canvas probe; backend selection probes WebGL2 only when that result is needed.
    • Source: the synthetic fixture has not been executed in this page yet.
    • Auto prefers WebGPU and reports the WebGL2 compatibility path explicitly. Forced backends never silently degrade to another backend or a CPU/Canvas2D path.
    • Nearest/pixel-perfect integer scaling with black letterbox. No CSS blur, no FSR/DLSS/AI upscaling, no vendor SDK. GLSL compute/storage-buffer features are not available on WebGL2; none are claimed.
    • No playable ROM, cartridge picker or retail save data in this foundation. The windowed shell exposes touch/pointer buttons, keyboard bindings, fullscreen and a persisted settings page; these map the documented KEYINPUT bits to the synthetic demo UI and are not a retail-game input path. The savegame panel is a host-side library for synthetic raw backup images, not guest save execution. Android/iOS packages remain open work (#11, #25).
